# Pip과 함께 가족 영어

아들·딸·아빠·엄마가 함께 쓰는 가족 영어 회화 웹앱입니다.

- 가족 영어 시간 20분: 노래 → 따라쟁이·몸 반응 → 가족 역할극 → 잠자리 이야기
- 딸 혼자 연습: 섀도잉, Pip과 대화 (하루 30분)
- 아빠·엄마 출퇴근 연습: 아이에게 쓸 문장
- 난이도 1~5, 사람별 설정

## 개인정보
- 이름, 사진, 학교, 주소 등 개인정보를 묻거나 저장하지 않습니다.
- 학습 기록은 기본적으로 사용하는 기기 안(브라우저 저장소)에만 저장됩니다.
- 보호자가 **가족 계정(선택)**에 카카오·네이버로 로그인하면, 기기끼리 기록을 맞추기 위해 서버에 다음만 저장합니다:
  회원 식별값(서버 비밀키로 변환한 값), 가족 번호, 역할(아들·딸·아빠·엄마)별 학습 기록, 보호자 동의 일시.
  이름·이메일·닉네임·사진·전화번호·음성·말한 문장·접속 IP는 저장하지 않습니다.
- 가족 계정은 앱에서 즉시 삭제할 수 있고, 3개월 동안 아무도 쓰지 않으면 자동 삭제됩니다.
- 음성 녹음은 저장하지 않습니다. 음성 인식을 쓰면 브라우저의 음성 인식 서비스로 소리가 전송될 수 있습니다.

## 가족 계정 서버
`worker/` 폴더 (Cloudflare Workers + D1, 무료 요금제). 설정 방법은 [worker/SETUP.md](worker/SETUP.md).

`index.html` 안의 `WEEK` 객체가 한 주 콘텐츠입니다. 매주 이 부분만 바꾸면 됩니다.
